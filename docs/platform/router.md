# Router

Selects the best model/tool/solver for each task.

## Components

- **router.py**: Main routing logic
- **registry.py**: Capability card storage
- **history.py**: Past routing decisions
- **policy.py**: Selection policy (rule-based/RL)
- **trainer.py**: Policy optimization
- **selector.py**: Candidate selection
- **confidence.py**: Confidence scoring
- **exploration.py**: Exploration strategy
- **reward.py**: Outcome scoring
