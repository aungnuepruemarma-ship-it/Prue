# Graph System

Fractal graph structure for multi-scale memory representation.

## Features

- Hierarchical graph with parent/child relations
- Fractal/self-similar structure
- Coarse-to-fine traversal
- Graph compression
- Multi-scale indexing

## Operations

- Merge: Collapse structure into super-nodes
- Split: Partition into subgraphs
- Expand: Abstract to detailed
- Query: Node/path/motif retrieval
