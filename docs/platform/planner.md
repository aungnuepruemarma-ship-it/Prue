# Planner

Converts goals into executable plans through decomposition and search.

## Components

- **planner.py**: Main planning orchestrator
- **decomposition.py**: Goal splitting into subtasks
- **search.py**: Beam search for candidate plans
- **heuristics.py**: Cost/guidance functions
- **objective.py**: Plan scoring
- **verification.py**: Plan validation
- **validator.py**: Constraint checking
- **repair.py**: Plan fixing
