# Memory System

Hierarchical memory with multiple tiers and fractal graph structure.

## Tiers

1. **Working**: Fast, short-lived buffer
2. **Session**: Task-level traces
3. **Episodic**: Task episodes with timestamps
4. **Semantic**: Distilled facts and concepts
5. **Procedural**: Reusable workflows
6. **Skill**: Versioned capabilities
7. **Archive**: Cold compressed storage

## Processes

- **Consolidation**: Move short-term to long-term
- **Replay**: Select items for retraining
- **Forgetting**: Decay unused memories
- **Retrieval**: Multi-scale search
